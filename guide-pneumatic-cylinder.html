공압 실린더 선정 방법 — 추력 계산 공식과 보어 사이즈 결정

PartsOn 엔지니어링 가이드 · 2026.07 업데이트

공압 실린더 선정의 핵심은 필요 추력을 만족하는 보어(튜브 내경)를 찾는 것입니다. 여기에 스트로크, 장착 형태, 쿠션, 속도 조건이 더해집니다. ISO 6431 표준 기준으로 선정 절차를 정리합니다.

1. 이론 추력 계산

전진(푸시) F = (π/4) × D² × P
후진(풀) F = (π/4) × (D² − d²) × P

D: 보어 지름 (mm), d: 로드 지름 (mm), P: 사용 압력 (MPa)
결과 단위: N

예: 보어 50mm, 0.5MPa → 전진 추력 = 0.785 × 2,500 × 0.5 ≈ 981 N (약 100 kgf)

2. 부하율 적용 — 실제 사용 추력

이론 추력을 100% 쓸 수는 없습니다. 마찰·배압 손실과 속도 확보를 위해 부하율을 적용합니다.

용도권장 부하율
정적 클램핑 (움직임 거의 없음)70%
수평 이송50%
고속 동작·수직 리프팅30~50%
필요 이론 추력 = 실제 필요 힘 / 부하율

예: 수평 이송에 50 kgf 필요 → 50/0.5 = 100 kgf → 보어 50 (0.5MPa 기준)

3. 보어 사이즈 결정

ISO 6431 표준 보어: 32, 40, 50, 63, 80, 100, 125mm. 위에서 구한 필요 이론 추력을 만족하는 최소 보어를 선택합니다. 압력은 공장 라인압(통상 0.4~0.6MPa)의 최저값으로 계산해야 안전합니다.

4. 스트로크와 로드 좌굴

  • 스트로크가 길고(300mm 이상) 로드에 압축·횡하중이 걸리면 로드 좌굴을 검토합니다
  • 횡하중이 큰 경우 가이드 부착형 실린더 또는 외부 LM가이드 병용을 권장합니다

5. 속도와 쿠션

  • 속도 제어는 미터아웃(배기 조절) 방식의 스피드 컨트롤러가 기본
  • 고속·중량물 정지 시 스트로크 끝 충격 흡수를 위해 에어쿠션 또는 쇼크업소버 적용
  • 필요 유량에 맞는 솔레노이드 밸브·배관 구경도 함께 확인 (밸브가 작으면 속도가 안 나옴)

6. 선정 예제

조건값
용도워크 수평 푸시, 필요 힘 60 kgf (≈588 N)
사용 압력0.5 MPa (최저 0.4 MPa)
부하율50%
필요 이론 추력 = 588 / 0.5 = 1,176 N
0.4 MPa 기준: (π/4)×D² ≥ 1,176/0.4 = 2,940 mm² → D ≥ 61.2 mm
→ ISO 표준 보어 63 선정
→ 공압 실린더 선정 계산기에서 직접 계산해보기 (SMC·Festo·CKD 3사 비교, 무료)

자주 묻는 질문

Q. SMC·Festo·CKD 어느 브랜드를 써야 하나요?

성능은 동급이며 기존 설비와의 호환성, 납기, 가격으로 결정하는 경우가 많습니다. PartsOn 계산기는 3사 동등 모델을 동시에 비교해 줍니다.

Q. 공기 소비량은 어떻게 구하나요?

1왕복 소비량 ≈ 실린더 체적 × (사용압+0.1)/0.1 (ANR 환산). 분당 왕복수를 곱하면 컴프레서 용량 검토에 사용할 수 있습니다.
