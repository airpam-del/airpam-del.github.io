# PartsOn — 자동화 부품 선정 플랫폼

데이터 기반 계산으로 정밀 부품을 빠르게 선정하고, 최적의 공급사와 즉시 연결되는 자동화 부품 선정 플랫폼입니다.

## 🎯 주요 기능

- **LM Guide 선정**: ISO 기준 모델 선정 및 수명 계산
- **볼스크류 선정**: 이송 조건과 하중으로 최적 조합 추천
- **베어링 선정**: 하중·회전수·사용 조건으로 타입 선정
- **서보모터 선정**: 부하 조건으로 필요 토크·관성 계산

## 🎨 UI/UX 개선사항

- 현대적 타이포그래피 (Space Grotesk + Pretendard)
- 부드러운 애니메이션 및 호버 효과
- 완전 반응형 디자인 (모바일/태블릿/데스크톱)
- 세련된 색상 팔레트 (다크 그린 + 라임 그린)
- GPU 가속 애니메이션 (60fps)
